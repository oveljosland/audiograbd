# audiograbd
The Audiograb is an embedded wireless environmental monitoring system, with on-device speech removal and species analysis with BirdNET. It is currently in development by students at NTNU for the Norwegian Institute of Nature Research ([NINA](https://www.nina.no/english/Home)). This repository contains the source code for the Audiograb daemon, ``audiograbd``. The PCB design files are available [here](https://github.com/oveljosland/audiograb-pcb).
